# Практическая работа №3
## Визуализация алгоритмов сортировки и бинарного поиска


## Цель работы
Разработать интерактивное приложение на PyGame для пошаговой визуализации трёх алгоритмов: пузырьковой сортировки, сортировки выбором и бинарного поиска.

## Архитектура проекта

### Модули
- `settings.py` — константы, цвета, параметры окна
- `algorithms.py` — генераторы шагов алгоритмов (без импорта PyGame)
- `visualizer.py` — класс отрисовки массива и интерфейса
- `main.py` — окно, event loop, управление состоянием

### Разделение ответственности
- Алгоритмы возвращают описание шага (словарь с типом и индексами)
- Визуализатор интерпретирует шаг и отображает его
- Алгоритмы не знают о графике, визуализатор не знает о логике сортировки

## Реализованные алгоритмы

### 1. Пузырьковая сортировка (Bubble Sort)
- Пошаговый генератор с yield
- Оптимизация раннего завершения (если не было обменов)
- Отображение: сравниваемые элементы (жёлтый), обмен (красный), отсортированные (зелёный)
- Статистика: Comparisons, Swaps, Pass, Steps

### 2. Сортировка выбором (Selection Sort)
- Поиск минимума в неотсортированной части
- Отображение: текущий минимум (оранжевый), проверяемый элемент (жёлтый), обмен (красный)
- Статистика: Comparisons, Swaps, Pass, Steps

### 3. Бинарный поиск (Binary Search)
- Работает только по отсортированному массиву
- Отображение: активный диапазон (голубой), mid (фиолетовый), исключённые (серый), найденный (зелёный)
- Ввод искомого значения через клавишу T
- Статистика: Target, Comparisons, Steps, Result

## Управление
- **1** — Bubble Sort
- **2** — Selection Sort
- **3** — Binary Search
- **SPACE** — запуск / пауза
- **N** — один шаг
- **R** — новый массив
- **T** — задать target (для бинарного поиска)
- **ESC** — выход

## Ключевые решения

### Пошаговое выполнение через генераторы
Алгоритмы реализованы как генераторы с yield. Каждый шаг возвращает словарь с типом операции и индексами. Это позволяет визуализатору показывать промежуточные состояния без блокировки основного цикла.
