# Практическая работа №4 — поиск пути

Приложение визуализирует поиск пути на сетке с препятствиями и клетками повышенной стоимости. BFS ищет путь с минимальным числом шагов, а алгоритмы Дейкстры и A* учитывают стоимость переходов. A* использует манхэттенское расстояние. Движение возможно по четырём направлениям.

## Запуск

В папке `practice_04` выполните:

```bash
python -m pip install pygame
python main.py
```

## Управление

- Левая кнопка мыши — поставить стену, правая — очистить клетку.
- `S` + левая кнопка — начало, `G` + левая кнопка — цель, `W` + левая кнопка — клетка повышенной стоимости.
- `1`, `2`, `3` — BFS, Дейкстра, A* соответственно.
- `Space` — запуск и пауза, `N` — один шаг.
- `R` — сброс поиска, `C` — очистка карты, стрелки вверх и вниз — скорость, `Esc` — выход.

Справа показаны статистика, состояния поиска и легенда цветов. Изменение карты сбрасывает текущий поиск.

## Файлы

- `main.py` — события, состояние приложения и шаги поиска.
- `grid.py` — клетки, соседи и стоимость переходов.
- `algorithms.py` — генераторы шагов BFS, Дейкстры и A*.
- `visualizer.py` — сетка и панель; `settings.py` — настройки.
