
# Задания для самостоятельной работы

В ходе практической работы необходимо разработать программу обработки растровых изображений на Python с использованием библиотек **Pillow** и **NumPy**.  
Работа должна представлять собой не набор разрозненных команд, а законченную программу, которая последовательно выполняет все перечисленные ниже задания.

### Задание 1. Загрузка и исследование изображения

1. Загрузить исходное изображение в формате JPEG или PNG.
2. Вывести в консоль:
   - имя файла;
   - формат изображения;
   - размер изображения;
   - цветовой режим Pillow;
   - ширину и высоту;
   - наличие или отсутствие альфа-канала.
3. Преобразовать изображение в массив NumPy.
4. Вывести:
   - `shape`;
   - `dtype`;
   - минимальное и максимальное значения элементов массива;
   - количество каналов.
5. Вывести значения RGB как минимум для трех выбранных пикселей изображения.

Студент должен уметь объяснить различие между:

```python
image.size
```

и

```python
array.shape
```

а также объяснить порядок измерений массива изображения.

---

### Задание 2. Работа с цветовыми каналами

Используя NumPy:

1. Получить отдельно красный, зеленый и синий каналы изображения.
2. Для каждого канала определить:
   - минимальное значение;
   - максимальное значение;
   - среднее значение интенсивности.
3. Создать три изображения, в каждом из которых сохранен только один цветовой канал:
   - красный;
   - зеленый;
   - синий.
4. Сохранить результаты в отдельные файлы.

Студент должен самостоятельно реализовать работу с массивом, а не использовать готовую функцию выделения каналов Pillow как единственный способ решения.

---

### Задание 3. Преобразование яркости средствами NumPy

Реализовать функцию изменения яркости изображения:

```python
def change_brightness(image_array, delta):
    ...
```

Функция должна:

1. принимать массив изображения;
2. изменять значения RGB-компонентов на величину `delta`;
3. корректно обрабатывать выход значений за диапазон `[0, 255]`;
4. возвращать массив типа `uint8`.

Необходимо сформировать:

- затемненное изображение;
- осветленное изображение.

Не допускается некорректное переполнение `uint8`.

Например, значение:

```text
250 + 20
```

не должно превращаться в небольшое число из-за переполнения типа данных.

---

### Задание 4. Изменение размера изображения

Создать не менее трех версий исходного изображения:

1. уменьшенную до 50 % исходного размера;
2. увеличенную в 1,5 раза;
3. приведенную к заданной ширине с сохранением пропорций.

Для последнего случая необходимо самостоятельно вычислить новую высоту:

```text
new_height = old_height × new_width / old_width
```

Для изменения размера использовать корректный алгоритм ресэмплинга Pillow.

Студент должен уметь объяснить, почему простое изменение размера массива и изменение разрешения изображения — не одно и то же.

---

### Задание 5. Поворот изображения

Создать функцию или отдельный блок программы, выполняющий поворот изображения на:

- 45°;
- 90°;
- произвольный угол, задаваемый пользователем.

Для поворота на произвольный угол необходимо:

1. сохранить изображение полностью;
2. избежать обрезания углов;
3. использовать подходящий метод интерполяции;
4. явно определить цвет вновь появившихся областей.

Необходимо сравнить результаты поворота с параметром:

```python
expand=False
```

и:

```python
expand=True
```

и объяснить различие.

---

### Задание 6. Преобразование в оттенки серого

Получить grayscale-изображение двумя способами:

1. средствами Pillow;
2. самостоятельно через NumPy.

Для NumPy использовать взвешенное преобразование RGB-компонентов в яркость.

Допускается формула вида:

```text
Y = 0.299R + 0.587G + 0.114B
```

После выполнения необходимо:

1. сохранить оба результата;
2. сравнить их;
3. объяснить, почему простое среднее:

```text
(R + G + B) / 3
```

не является корректной моделью воспринимаемой яркости.

---

### Задание 7. Обработка области изображения

Выбрать прямоугольную область исходного изображения и выполнить над ней локальное преобразование.

Необходимо:

1. определить координаты области;
2. изменить только выбранную часть изображения;
3. оставить остальную часть изображения без изменений.

В выбранной области выполнить одно из преобразований:

- перевод в grayscale;
- уменьшение яркости;
- усиление одного из цветовых каналов.

Таким образом студент должен продемонстрировать понимание срезов NumPy:

```python
array[y1:y2, x1:x2]
```

### Задание 8. Формирование итогового изображения

Сформировать итоговую композицию, содержащую не менее шести результатов обработки:

1. исходное изображение;
2. уменьшенное;
3. повернутое;
4. grayscale;
5. изображение с измененной яркостью;
6. изображение с локально обработанной областью.

Допускается использовать Matplotlib исключительно для визуализации результатов.

Каждое изображение должно иметь понятный заголовок.

---

### Задание 9. Организация программы

Программа должна содержать функцию `main()` и отдельные функции минимум для следующих операций:

```python
load_image(...)
change_brightness(...)
resize_keep_aspect(...)
to_grayscale_numpy(...)
process_region(...)
save_result(...)
```

Не допускается размещение всей логики программы одним непрерывным блоком.

Пример:

```python
def main():
    image = load_image(...)
    ...
    

if __name__ == "__main__":
    main()
```

---

### Задание 10. Обработка ошибок

Программа должна корректно обрабатывать как минимум следующие ситуации:

- файл изображения не найден;
- передан файл неподдерживаемого формата;
- задано некорректное значение угла;
- задан некорректный размер изображения;
- координаты области обработки выходят за пределы изображения.

Сообщения об ошибках должны быть понятными пользователю.
